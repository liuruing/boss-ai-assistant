# Boss AI Assistant

一个基于人工智能的自动化求职助手，帮助用户在 Boss 直聘平台上自动投递简历并生成个性化的打招呼语句。

## 项目简介

Boss AI Assistant 是一个自动化工具，旨在简化求职过程。它利用 AI 技术分析职位描述和您的简历，生成有针对性的打招呼语句，并通过自动化流程帮助您在 Boss 直聘平台上投递简历。

## 主要功能

- 分析职位描述与您的简历，生成个性化的打招呼语句
- 自动投递简历到符合条件的职位

## 安装与使用

### 前提条件

- Chrome 浏览器

### 安装步骤
   
chrome插件的标准安装方式，安装后在浏览器右上角点击插件图标即可使用。

## 注意事项

- 请确保关闭 Boss 直聘账户中的默认打招呼语句，以免影响程序运行
- 使用本工具时请遵守相关平台的使用条款
- 建议适度使用，避免频繁操作导致账号异常
